Алгоритмы и структуры данных

Алгоритм Кнута — Морриса — Пратта (КМП / KMP)
Эффективный алгоритм поиска подстроки в строке, который избегает повторного отката по тексту благодаря предварительному анализу искомого шаблона.
Алгоритм Кнута — Бендикса
Алгоритм в компьютерной алгебре, который пытается преобразовать набор математических равенств в систему переписывания термов (используется для автоматического доказательства теорем).
Алгоритм X (Knuth's Algorithm X)
Рекурсивный алгоритм поиска с возвратом (backtracking), предназначенный для решения задачи точного покрытия (на нём базируются программы для решения судоку и пентамино).
Танцующие ссылки (Dancing Links / DLX)
Высокоэффективная техника реализации Алгоритма X с использованием двусвязных списков, разработанная Кнутом.
